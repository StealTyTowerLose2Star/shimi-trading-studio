# 拾米平台推进方案（产品总纲 v1.0 · 2026-11-08）

> 产品经理：Kimi。本文回答"拾米往哪走、先做什么后做什么"。AI 迭代方案是其 P2 阶段的执行子方案。

## 一、一句话定位

**拾米 = 本人的投资研究助手：用真实数据和可检验的证据，帮你做"更少、更有纪律"的研究决策。**
不是荐股神器、不是自动交易系统、不承诺任何收益。

## 二、现状盘点（不粉饰）

| 维度 | 现状 | 判断 |
|---|---|---|
| 数据与功能 | 全模块真实数据（A股/美股/策略/翻倍/复盘/记账），8 commit 上 GitHub | ✅ 骨架完整 |
| 工程质量 | 独立验收+反例驱动修复，real-only 无假数据 | ✅ 可信 |
| **策略有效性** | **趋势策略回测 -57.08% vs 基准 -19.18%（超额 -37.9pp）** | ❌ **最大短板：策略目前跑输最笨方法** |
| 使用价值 | 尚未形成"本人每天用它做研究"的习惯与收益证据 | ⬜ 待验证 |

**结论：平台当前处于"工具完整、策略未证有效"阶段。继续堆功能没有价值，唯一主线是证明策略能跑赢基准。**

## 三、推进主线（按优先级）

1. **策略有效性（唯一价值主线）**：AI 迭代方案 I1→I4，把超额收益收敛到 >0 且样本外稳定
2. **真实使用闭环**：本人每周固定用拾米做 1 次复盘（复盘/建议/回测三件套），记录"有没有帮你省时间/避坑"——这是价值的一手证据
3. **稳定性维护（保底，不再扩）**：现有模块保持可用，缺陷随用随修，不开新模块

## 四、阶段路线图

| 阶段 | 目标 | 达标口径 | 当前 |
|---|---|---|---|
| P1 证据基建 | 真实数据+回测基准+独立验收 | 已完成 | ✅ |
| P2 策略达标 | 样本外超额>0pp、多窗口过半为正、回撤可控 | AI 迭代 I1–I4 全套门槛 | 🟡 主线 |
| P3 个人价值验证 | 本人连续 4 周真实使用，复盘有明确帮助 | 每周使用记录+主观/客观反馈 | ⬜ P2 并行可做 |
| P4 小范围开放 | 他人试用 | 本人批准+合规专项（荐股资质/免责/数据许可） | ⬜ 冻结 |

## 五、关键原则（防走偏）

- **先证明有用，再谈平台**：P2 不达标，不新增任何功能/数据源/付费服务
- **AI 是研究助手不是操盘手**：AI 只做归因/假设/报告，买卖决策永远在人
- **不自动交易、不代客理财、不承诺收益**：合规底线，P4 开放前需专项评估
- **坏消息照报**：策略跑输、实验失败都如实呈现，不挑好看的窗口

## 六、每周节奏（本人只需两处投入）

- **你**：①每周一次用拾米做复盘（15 分钟内）②AI 迭代出新版本时，看"考试成绩对比"拍板换不换
- **我**：策略迭代、实验留痕、缺陷修复、每周五平台周报（手机推送）
- **Codex**：独立验收；**AI Agent（K3.1 Pro）**：亏损归因/假设生成

## 八、长期愿景与资本路径（2026-11-11 本人确定）

**长期目标：万卡算力、大模型、高频交易、海量多源数据。路径：先通过算法赚足够的钱，再用盈利采购算力卡、部署模型、扩展数据。**

| 阶段 | 目标 | 进入条件（证据换门票） |
|---|---|---|
| V0 算法证据 | 策略样本外稳定跑赢基准 | I3/I4 实验+灰度观察达标（当前阶段） |
| V1 小资金实盘验证 | 真实市场验证策略与执行（手动记账先行，券商 API 仍禁） | V0 达标 + **本人另行批准实盘** |
| V2 稳定盈利 | 覆盖数据/算力/交易成本，形成正现金流 | V1 连续两个季度稳定盈利且回撤可控 |
| V3 算力与数据扩容 | 按盈利分级采购 GPU/多源数据、部署研究模型 | V2 现金流覆盖采购预算，不提前负债 |
| V4 AI 量化平台 | 大模型辅助研究、多源数据、更高频能力评估 | V3 基础稳固后逐项评估；高频需另做实时数据/执行/合规专项 |

**纪律**：愿景不改变当前节奏——不为未来目标提前采购、不提前负债、不用"以后要赚钱"放松当前验收标准；高频是数据、执行、合规完全不同的赛道，届时单独评估，不默认必须走到高频。

## 八、当前决策点

1. 已批准：AI 迭代 I1/I2 启动（首轮基线实验进行中）
2. 待产出确认：Top3 缺陷+≤3 条假设（I2 归因报告）→ 进入 I3 验证
3. 冻结：新功能、新数据源、付费服务、对外开放
