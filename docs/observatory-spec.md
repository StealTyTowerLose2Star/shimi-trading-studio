# 观星台 (Observatory) · 市场事件监控

> 观天象、察风云，监测影响市场的一切事件，映射到具体标的，生成多空信号

---

## 一、功能大纲

### 1. 数据采集层

| 功能 | 数据源 | 频率 | 产出 |
|:---|:---|:---|:---|
| 政策事件 | 巨潮资讯 + 国务院/发改委公告 | 日级 | 政策信号列表 |
| 财报日历 | yfinance (美股) + tushare (A股) | 日级 | 财报窗口预警 |
| 宏观数据 | Finnhub News + 东方财富要闻 | 日级 | 宏观事件列表 |
| 行业动态 | 东方财富行业板块 | 实时 | 行业轮动信号 |
| 商品价格 | 东方财富期货 | 实时 | 商品景气跟踪 |
| 地缘事件 | Finnhub News + 新闻聚合 | 日级 | 高风险预警 |

### 2. 事件分析层

| 功能 | 说明 |
|:---|:---|
| 事件分类 | 6类型自动分类 (政策/财报/宏观/地缘/行业/商品) |
| 影响评级 | high/medium/low 三级,基于关键词权重 |
| 持续时间 | 每种事件类型的预期影响周期 (7/14/30/60天) |
| 事件去重 | 基于标题相似度去重,避免重复告警 |

### 3. 标的映射层

| 功能 | 说明 |
|:---|:---|
| 行业→股票映射 | 13行业 × 78只A股+美股核心标的 |
| 供应链映射 | 上下游企业自动关联 |
| 多空方向推断 | 基于事件语义分析 (利好→做多,利空→做空) |
| 影响程度量化 | 事件影响力 × 标的相关性 = 信号强度 |

### 4. 信号输出层

| 功能 | 说明 |
|:---|:---|
| API端点 | `/api/market/events` (查询) + `/api/market/events/refresh` (刷新) |
| 消息推送 | 高影响事件 → message_queue → 通讯员 → 微信/Webhook |
| 每日摘要 | 事件汇总自动加入 cron_daily_digest |
| 魔法师集成 | 政策/行业事件 → catalyst_engine 加分 (C1/C6) |

---

## 二、技术规格

| 指标 | 值 |
|:---|:---|
| 事件来源 | 6个 (巨潮/Finnhub/yfinance/东方财富/新闻/期货) |
| 事件类型 | 6种 (政策/财报/宏观/地缘/行业/商品) |
| 标的覆盖 | 78只 (A股48 + 美股30) |
| 更新频率 | 每30分钟 (cron) + 手动刷新 |
| 存储 | JSON文件 (90天保留) |
| 耦合 | 零跨市场引用 ✅ |
