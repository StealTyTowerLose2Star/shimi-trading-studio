## 一、学术理论基础

### 1.1 量化选股因子体系 (Fama-French + 扩展)

```
经典因子:
  Fama-French 3因子: 市场β + 规模(SMB) + 价值(HML)
  Carhart 4因子:   + 动量(MOM)
  Fama-French 5因子: + 盈利(RMW) + 投资(CMA)

拾米已实现:
  D1 价格区间 (价值因子)     D4 动量强度 (动量因子)
  D2 行业热度 (板块因子)     D5 换手率   (流动性因子)
  D3 市值弹性 (规模因子)     D6 板块属性 (市场因子)
```

### 1.2 机器学习预测模型 (QEPM框架)

| 模型 | 适用场景 | 成熟度 | 建议 |
|:---|:---|:---|:---|
| **Logistic Regression** | 涨跌二分类 | ⭐⭐⭐⭐⭐ | 基准模型,必须实现 |
| **Random Forest** | 特征重要性排序 | ⭐⭐⭐⭐⭐ | 替代当前规则权重 |
| **XGBoost/LightGBM** | 高维非线性 | ⭐⭐⭐⭐ | 月度翻倍预测最佳 |
| **LSTM/GRU** | 时序价格预测 | ⭐⭐⭐ | 需大量数据,暂不适合 |
| **Transformer** | 多变量时序 | ⭐⭐ | 研究阶段,不推荐生产 |

### 1.3 集成学习 (Ensemble)

```
Stacking 架构:
  基学习器: Logistic + RandomForest + XGBoost
  元学习器: Logistic Regression
  输出: 涨跌概率 + 置信区间

优势: 降低过拟合, 提高泛化能力
拾米适配: 替换当前 D1-D10 固定权重为 ML 权重
```

## 二、实操框架

### 2.1 训练-验证-测试分离

```
时间序列切分 (禁止随机):
  训练集: 2023-01 ~ 2025-06 (30个月)
  验证集: 2025-07 ~ 2025-12 (6个月)
  测试集: 2026-01 ~ 至今     (滚动预测)

关键约束:
  ❌ 禁止随机 shuffle (时序数据 leak)
  ❌ 禁止使用未来数据 (前视偏差)
  ✅ 滚动窗口验证 (walk-forward)
```

### 2.2 特征工程 (102维 → 精选15维)

```
已实现: D1-D10 (10维)
建议新增:
  D11 机构持仓变化    季度数据,滞后1个月
  D12 北向资金流向    日度,沪深港通
  D13 龙虎榜净买入    日度,游资信号
  D14 融资余额变化    日度,杠杆情绪
  D15 波动率锥 (IV/HV) 期权隐含波动率 vs 历史波动率
```

### 2.3 评估指标

| 指标 | 公式 | 目标 |
|:---|:---|:---|
| **准确率** | (TP+TN)/Total | >60% |
| **精确率** | TP/(TP+FP) | >50% (降低假阳性) |
| **召回率** | TP/(TP+FN) | >40% (不错过翻倍股) |
| **F1-Score** | 2*P*R/(P+R) | >0.45 |
| **夏普比率** | (Rp-Rf)/σp | >1.5 |
| **最大回撤** | max(peak-trough)/peak | <20% |

### 2.4 过拟合防护

```
1. 特征数量 < 样本数量/10
2. L1/L2 正则化 (XGBoost: reg_alpha, reg_lambda)
3. 早停 (early_stopping_rounds=20)
4. 交叉验证 (TimeSeriesSplit, n_splits=5)
5. 特征重要性剪枝 (去除 importance<1% 的特征)
```

## 三、项目落地设计

### 3.1 模块架构 (零耦合)

```
新模块: services/predictor.py (预测引擎)
  ├── 输入: data/fetcher.py (统一数据)
  ├── 模型: sklearn/xgboost (训练+推理)
  ├── 输出: 涨跌概率 + 置信区间
  └── 集成: 魔法师 doubler_scanner 调用 predictor

新模块: services/backtest.py (回测框架)
  ├── 输入: 历史数据 + 预测结果
  ├── 输出: 夏普比率/最大回撤/胜率
  └── 报告: 自动生成回测报告
```

