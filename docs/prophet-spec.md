# 先知 (Prophet) · ML预测引擎

> 以数据为基，预判翻倍机会。补充规则引擎，用ML学习历史翻倍股规律

---

## 一、功能大纲

### 1. 数据准备层

| 功能 | 说明 |
|:---|:---|
| 训练数据构建 | 历史翻倍股(正样本) + 随机非翻倍股(负样本) |
| 特征工程 | 15维特征 (D1-D10已有 + D11-D15新增) |
| 标签定义 | 月涨幅≥100% → 正样本 (1), 否则负样本 (0) |
| 数据清洗 | 去ST/去停牌/去新股/去极端值 |
| 时序切分 | 训练2023-25 / 验证2025H2 / 测试2026 (walk-forward) |

### 2. 模型训练层

| 模型 | 适用场景 | 优先级 |
|:---|:---|:---|
| Logistic Regression | 涨跌二分类基准 | P0 |
| Random Forest | 特征重要性排序 | P1 |
| XGBoost | 高维非线性翻倍预测 | P1 |
| Stacking Ensemble | 降低过拟合,提高泛化 | P2 |

### 3. 推理预测层

| 功能 | 说明 |
|:---|:---|
| 月度预测 | 每月1日全市场扫描,输出翻倍概率 Top 30 |
| 实时推理 | 单股查询 `/api/prophet/predict?code=000001` |
| 概率校准 | Platt Scaling 校准输出概率 |
| 置信区间 | 输出 95% 置信区间 |

### 4. 回测验证层

| 功能 | 说明 |
|:---|:---|
| 历史回测 | 2023-2025 滚动窗口,每月预测 → 实际验证 |
| 绩效指标 | 准确率/精确率/召回率/F1/夏普/最大回撤 |
| 模型对比 | 规则引擎 vs ML引擎 vs Stacking 对比 |
| 报告生成 | 月度回测报告 → message_queue → 通讯员 |

### 5. 模型管理

| 功能 | 说明 |
|:---|:---|
| 版本管理 | 每次训练生成新版本号 (YYYYMMDD) |
| A/B测试 | 规则引擎 vs ML引擎 并行运行,月度对比 |
| 权重融合 | 规则×0.4 + ML×0.6 (可配置) |
| 自动重训 | 每月新增翻倍股数据后自动重训 |

---

## 二、技术规格

| 指标 | 值 |
|:---|:---|
| 特征维度 | 15 (D1-D15) |
| 训练样本 | 历史翻倍股(正) + 随机采样(负) ≈ 5000条 |
| 模型库 | sklearn + xgboost |
| 训练频率 | 每月1日自动重训 |
| 推理延迟 | <100ms (单股), <5s (全市场) |
| 存储 | pickle模型文件 + JSON参数 |
| 耦合 | 零跨市场引用 ✅ |

## 三、核心公式

```
翻倍概率 = P(月涨幅 ≥ 100% | 15维特征)

集成评分 = 规则评分×0.4 + ML概率×100×0.6

精英池 = Top 30 (按集成评分降序)
  - 排除: ST/月涨幅>50%/连续涨停≥3天
  - 优先: 启动前期 + 催化剂共振 + ML高置信
```
