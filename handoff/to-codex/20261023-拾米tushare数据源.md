## 切换要点

- 数据后端 `local_tushare_data.py`（urllib 直连 POST，零第三方依赖；venv 内 tushare 包未使用）。
  函数契约与东财备用后端 `local_real_data.py` 完全一致，`local_run.py` 仅改 import 一行接线。
- 传输验收：API_URL 由 HTTP 切至 **HTTPS**（此前 fail-closed 拒绝明文）。2026-10-24 本机实测
  `https://api.tushare.pro` 直连成功（trade_cal/daily/index_daily/stock_basic/daily_basic/us_basic/us_daily）。
- 双闸门（读令牌前强制）：传输非 HTTPS → `transport_not_verified`；
  `SHIMI_MARKET_USE != personal_view` → `purpose_unconfirmed`（commercial 明确拒绝）。
- 凭据流：`restart-local.ps1` 从注册表 User 作用域读 `TUSHARE_TOKEN`/`SHIMI_MARKET_USE`
  到进程环境（不回显、不落盘、不改系统配置）→ `local_safe_start.py start` 白名单继承；
  `preflight` 保持无凭据。token 值不出现在任何代码/日志/文档/diff 中（已 grep 验证）。
- EOD 口径：盘中"最新"= 最近一个有日线数据的交易日收盘（trade_cal 驱动自动回退）；
  响应带 `trade_date`/`retrieved_at_utc`/`source` 元数据，首页横幅按凭据状态动态声明。
