## 范围声明（操作者授权）

本人 2026-10-26 授权启用「交易日志/交易记录」模块，**仅限手动记录**：
手动录入/修改/删除交易流水（买入/卖出：代码、日期、价格、数量、费用可选），本地 SQLite 存储不出本机；
持仓与盈亏用 tushare 真实收盘价（EOD）计算。**严格禁止**：券商 API、自动下单、买卖建议/荐股文案、
webhook 推送——本模块是纯记账+算账，文案不出现任何买卖建议导向（离线测试固化该红线）。

## API 清单（均需登录 Bearer token；写路径仅本机 host 双保险）

| 方法 | 路径 | 说明 |
|:--|:--|:--|
| GET | `/api/trades` | 流水列表 + 汇总（总笔数/持仓数/已实现盈亏） |
| POST | `/api/trades` | 录入 `{date, code, side:buy/sell, price, qty, fee?, note?}`；名称自动从名录补全 |
| PUT | `/api/trades/<id>` | 修改（改后重放该标的全部流水，破坏持仓一致性则 400 拒绝且不破坏原记录） |
| DELETE | `/api/trades/<id>` | 删除（删除买入导致后续卖出超持仓则 400 拒绝） |
| GET | `/api/trades/portfolio` | 持仓视图：每标的 qty/avg_cost/现价/市值/浮盈/已实现 + 组合汇总 |

仍禁用：`/api/trade`（单数，上游券商面）POST 403；`/api/trades/batch/*` 批量操作未放行；未登录一律 401。

## 成本核算口径：移动加权平均成本

- 买入：`新成本价 = (旧成本价×旧数量 + 买入价×数量 + 买入费用) / 新总数量`（**费用摊入成本**）
- 卖出：`已实现盈亏 += (卖出价 − 成本价)×数量 − 卖出费用`；**持仓成本价不变**（部分卖出不摊薄）
- 清仓（数量归 0）：成本价重置为 0，全部盈亏已结入 realized
- 浮动盈亏 = (最新 EOD 收盘 − 成本价) × 持仓数量；现价取不到 → `quote_status=unavailable`、
  浮盈/市值为 `null`、汇总 `quote_available` 显式计数，**绝不用 0 或合成价**
