# 拾米策略迭代实验目录规范（I1 · 2026-11-08）

## 目录结构

```
iteration/
  run_experiment.py            # 唯一实验入口 (walk-forward 多窗口)
  <时间戳>-<策略>-<标签>/       # 每次实验一个目录, 永不覆盖
    experiment.json            # 参数+代码git hash+数据口径 (复现依据)
    result.json                # 汇总+逐窗口明细+全量成交 (AI归因数据源)
    report.md                  # 人读摘要
```

## 纪律

- 每次实验新目录；结果只增不改；假设废弃也留档
- 窗口间无未来数据（`eval_end` 先截断 K 线再计算）；候选池幸存者偏差与 ST 时点偏差必须随结果披露
- 对照组必备：同窗口沪深300 买入持有；无基准的实验不进入评审
- I3 启用门槛：中位超额>0pp 且正超额窗口过半；回撤不劣于基准+5pp（后续版本加入基准回撤列）
- AI 只读 result.json 做归因/假设，不直接改线上参数；上线需本人确认+Codex 独立验收
